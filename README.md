# Производственная практика ПМ.08

**Разработка дизайна веб-приложений · 7 семестр · 2026–2027**

09.02.07 «Информационные системы и программирование», квалификация «Разработчик веб и мультимедийных приложений».

[Открыть учебный сайт](https://olgakraven.github.io/2026-2027-09.02.07-rvmp-pp-pm.08-sem07/)

Один учебный стек: Python, Flask и MySQL. Методичка последовательно показывает решение примера «Конференции.РФ»: создание базы, запуск начальной основы, подключение собственного CSS/JS, оформление кнопок и форм, подсказка заполнения, ошибки и фокус, карточки и мобильный экран. Каждый фрагмент сопровождается объяснением и проверкой.

Начните с «Задания», затем выполните «Инструкцию и образец». После разбора разработайте самостоятельный интерфейс своей предметной области. В комплекте 30 индивидуальных заданий и их учебные JSON-каталоги. В карточках областей размещены только данные конкретной области. Общий шаблон отчёта доступен на сайте.

Приложение запускается локально; GitHub Pages размещает методические материалы. Исходная основа содержит серверные функции и базовый интерфейс; собственный слой дизайна создаётся по методичке. Архивы завершённых решений и материалы преподавателя исключены из комплекта.

Учебное решение воспроизведено на Python/Flask/MySQL, 8 тестов приложения проходят. Проверены ошибки и фокус формы, пустой результат фильтра, мобильная регистрация 390×844.
