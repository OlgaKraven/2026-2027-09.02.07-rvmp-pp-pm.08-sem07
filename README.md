# Производственная практика ПМ.08

**Разработка дизайна веб-приложений · 7 семестр · 2026–2027**

[Открыть методичку](https://olgakraven.github.io/2026-2027-09.02.07-rvmp-pp-pm.08-sem07/lessons.html)

Методичка учит создавать пример «Конференции.РФ» самостоятельно с пустой папки на Python, Flask и MySQL. Каждый фрагмент объясняет структуру данных, маршрут, шаблон или приём дизайна и сопровождается проверкой. Код последовательно вводится в процессе разбора.

Готовое приложение, исходная основа для открытия, архивы проектов и скачивание полных файлов решения не предоставляются. В разделе предметных областей размещены только 30 JSON-каталогов с учебными данными. После разбора ученик разрабатывает собственный интерфейс и выполняет оба индивидуальных условия.

Проверены полный пользовательский сценарий, ошибки регистрации, роли, CSRF, вместимость, допустимые статусы, чужой и повторный отзыв; все 30 каталогов импортированы новым учебным кодом и проверены по фильтрам. Учебный пример выполнен на macOS с MySQL. Команды Windows сверены; Windows здесь не запускалась.

Сценарий основан на предоставленных автором материалах КИМ БУ 09.02.07-3-2027 и примере «Конференции.РФ». Все демонстрационные данные вымышленные. `content/course.json` и `teaching/` содержат редактируемые источники учебных фрагментов для методички; `site/` — опубликованные материалы.
