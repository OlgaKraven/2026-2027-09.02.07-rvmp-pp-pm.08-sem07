# Производственная практика ПМ.08

**Разработка дизайна веб-приложений · 7 семестр · 2026–2027**

09.02.07 «Информационные системы и программирование», квалификация «Разработчик веб и мультимедийных приложений».

[Открыть учебный сайт](https://olgakraven.github.io/2026-2027-09.02.07-rvmp-pp-pm.08-sem07/)

В комплекте 30 индивидуальных предметных областей, подробная инструкция и отдельный демонстрационный проект «Конференции.РФ». Выберите Flask + MySQL/MariaDB или PHP + MySQL/MariaDB. Исходные и демонстрационные архивы обеих веток доступны в каждой карточке вместе с её каталогом JSON.

Начните с раздела «Задание», затем откройте «Инструкция и образец». Приложения запускаются локально: GitHub Pages размещает методические материалы. Общий шаблон отчёта находится в `site/downloads/report-template.md`. При сдаче проекта приложите ссылку на его репозиторий.

## Воспроизводимость

Содержание — `content/course.json`. Проекты — `projects/`, каталоги — `data/`, последовательные учебные фрагменты — `design/`. Для черновой пересборки используйте `tools/Agent-Methodist/README.md`. Проверенная публикация находится в `site/`; `manifest.json` содержит контрольные суммы.

При подготовке выполнены 8 Flask-проверок на MySQL, PHP HTTP smoke, запуск всех 30 каталогов в обеих ветках и сборка демонстрации по последовательным фрагментам инструкции. Все страницы PDF и сайт просмотрены; мобильные экраны проверены при 390×844. Среда выполнения — macOS; графическая панель XAMPP на Windows отдельно не проверялась.
