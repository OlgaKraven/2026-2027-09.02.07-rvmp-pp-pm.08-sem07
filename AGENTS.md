# Учебная практика ПМ.08

Сохранять 7 семестр, 30 индивидуальных областей и единый стек Python/Flask/MySQL. Методичка должна учить самостоятельному созданию примера с пустой папки. Показывать код по последовательным смысловым фрагментам, объяснять назначение и давать проверку результата. Не предоставлять готовое приложение или начальную основу, архивы проектов, ссылки на открытие/скачивание приложения и скачивание полных файлов решения. В карточках областей разрешены только данные JSON. Не возвращать материалы преподавателя. Изменять источник содержания и пересобирать комплект. Сохранять поле ссылки на репозиторий ученического проекта. Перед публикацией выполнять реальные затронутые проверки и просматривать PDF и сайт. Не публиковать паспорт, состояние workflow, журналы, секреты и пользовательские базы. Отправлять через GitKraken/GitHub Desktop; при их недоступности использовать git push, уже явно разрешённый пользователем для публикации этой практики.
