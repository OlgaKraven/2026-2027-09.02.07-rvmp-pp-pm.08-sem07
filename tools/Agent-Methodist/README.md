# Сборка комплекта преподавателем
+
+Это локальный сборщик Agent-Methodist с поддержкой подписей загрузок и ссылок этой практики. Python не генерирует тексты и не вызывает модель.
+После подготовки зависимости requirements.txt выполните из tools/Agent-Methodist:
+python -m methodist validate ../..
+python -m methodist build ../..
+python -m methodist check ../..
+Это черновая сборка. Выпуск требует независимых реальных доказательств; опубликованный release не переносится на изменённые исходники автоматически.
