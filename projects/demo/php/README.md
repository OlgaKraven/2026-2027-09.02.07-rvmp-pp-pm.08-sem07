# Конференции.РФ — php

Общий демонстрационный проект после разбора дизайна практики ПМ.08, 7 семестр.
Источник: https://github.com/OlgaKraven/demo-rvpm-2027/tree/a5510ee36faaa291ff42a95066a4070c5e7be88f/examples/conference-portal-php
Изображения и PT Sans перенесены из исходного примера. Названия площадок — демонстрационные данные.
Запуск и последовательные изменения раскрыты в методичке практики. Сначала запускайте source, затем выполняйте изменения. demo нужен для сверки после собственной работы.
Используйте отдельную базу pm08_php_2027. MySQL/MariaDB; не объединяйте базы веток.
Учебный администратор: Conf2027 / Demo77. Эти реквизиты относятся только к локальному примеру.
GitHub Pages обслуживает методические материалы; серверный проект запускается локально.
